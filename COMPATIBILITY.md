# Compatibility

The plugin is currently released for the USA build of *Ratchet & Clank: Size Matters*.

| Region | Title ID | Status | Notes |
|---|---|---|---|
| USA | UCUS-98633 | Tested / Supported | Hardware-tested on PS Vita with Adrenaline/Epinephrine |
| Europe | UCES-00420 | Tested / Unsupported | Current USA signature/profile does not activate correctly |
| Japan | UCJS-10052 | Untested | No compatibility claim |
| Korea | UCKS-45048 | Untested | No compatibility claim |

## USA — UCUS-98633

This is the supported v1.0.0 target. Testing on real PS Vita hardware covered multiple planet transitions and included the Staff Off easter-egg area.

The plugin dynamically rediscovers level-dependent camera routes, but that does not make it automatically compatible with other regional builds.

## Europe — UCES-00420

This region has been tested and the current USA plugin does not work correctly with it. A separate regional camera signature/profile still needs to be reverse engineered and validated.

## Other regions

Japan and Korea are untested. No compatibility claim is made until their camera path is inspected and validated on the corresponding game build.
